# notes/

Satu catatan per modul di `src/`, nama sama (contoh: `remote.md`).

Template:

```
# <modul>
**Tujuan:** satu kalimat
**File:** src/<modul>
**Cara panggil:** contoh singkat
**Mekanisme:** bagaimana cara kerjanya
**Dependensi:** modul lain yang dipakai
**Gotcha:** bug/jebakan yang pernah muncul, alasan desain
```

Isi hanya hal yang TIDAK terlihat jelas dari kodenya.
